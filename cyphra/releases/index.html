Cyphra for Windows 1.6.3

Opens local folders and HTML files instead of searching the web for their paths.

  • Type or paste a local path such as F:\Notes\page.html (Explorer’s “Copy as path” works too): a folder shows its file listing and an HTML file opens as a page.
  • Double-clicking an .html file in a folder whose name has spaces now opens it in Cyphra. Before, both cases ran a Google search for the path.
  • Includes deep page analysis from 1.6.2.

1.6.2: Deep page analysis with Qwen 3.8

Ask the copilot to analyse the page you are on and get the data, metrics, insights and a strategy back.

1.3.0: Choose your local AI

Pick which local AI program Cyphra uses, and decide whether it uses your name.

  • Settings has a Local AI section: Ollama, or any OpenAI-compatible server on your PC (LM Studio, llama.cpp, Jan).
